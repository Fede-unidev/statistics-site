HW6 · Riemann vs Lebesgue, and the normal CDF

Ex. 1 · Riemann and Lebesgue integration

Riemann partitions the domain [a,b] into N subintervals and sums f(tag)·width (we use left, right, midpoint and trapezoid tags). Lebesgue partitions the range into levels y0 < … < yK and sums yj·μ(f−1[yj, yj+1)), the measure of the preimage of each slab. Two ways to get that measure are implemented: sampled (fraction of N midpoint samples whose value falls in the slab) and exact (closed-form measure of the sublevel set, available here because the preimages are intervals; it costs O(K) and uses no samples). Lower/upper sums use the bottom/top level of each slab, "mid" its centre.

Discussion (Ex. 1)




    

  • Same value when both exist. A Riemann-integrable function is Lebesgue-integrable with the same integral, and every smooth example above converges to the exact value in both approaches. The converse fails: Lebesgue integrability is strictly more general.
    • 

  • Smooth functions: Riemann wins in practice. Midpoint and trapezoid rules have error O(N−2) (about 10−13 for N = 106), left/right O(N−1) for x², sin(x)/x. For sin(x) on [0,π] left, right and trapezoid coincide because f(0) = f(π) = 0. The sampled Lebesgue sum is limited by the level width (≈ range/K) and by the sampling error of the measures: with K = √n it is still around 10−5 at 106 samples. Even with exact preimage measures, lower and upper sums bracket the integral with error O(1/K), only the mid-level version reaches O(K−2). The Lebesgue sum is a Riemann sum whose values were rounded to a grid of levels, so for smooth functions it cannot beat the Riemann sum computed on the same samples.
    • 

  • Discontinuous (step) functions. The Riemann sums converge, but only like 1/N, with a constant that depends on where the jump falls on the grid: with an odd N some rules are exact by coincidence (e.g. the trapezoid rule here), which is luck and not a better rate. A Lebesgue sum sees only two values and two measures, so with exact preimages the error does not depend on a mesh at all (the "mid" column is exact here because the errors of the two level sets cancel by symmetry; lower and upper still bracket the value with error 1/K). With sampled measures the error is again ≈ 1/N, because the measure of {x < 0.5} is estimated by counting samples. In short, the advantage of the Lebesgue view is only real when the preimage measures are available.
    • 

  • Unbounded function 1/√x. The Riemann sums with the endpoint x = 0 (left, trapezoid) are infinite: the Riemann integral is improper and defined as lim ∫ε1. The right and midpoint sums converge, but slowly, like N−1/2 (the error is dominated by the first subinterval: ∫0hx−1/2dx = 2√h, while the midpoint sum has √(2h)). The Lebesgue integral of a non-negative function needs no limit: with the layer-cake formula ∫f = ∫0∞ μ{f > t}dt = ∫0∞ min(1, 1/t²)dt = 1 + 1 = 2. Numerically the levels must be refined where f is large (we use yj ∝ (j/K)3, truncated at K²) and convergence is still slow (about K−2/3 in the table).
    • 

  • Dirichlet function. Every subinterval of every partition contains rationals and irrationals, so the upper Darboux sum is 1 and the lower is 0 for every partition: not Riemann-integrable. Riemann sums depend on the tags: rational tags give 1, irrational tags give 0 and any mixture gives anything in between. Lebesgue: {f = 1} = ℚ ∩ [0,1] is countable, hence has measure 0, so ∫f = 1·0 + 0·1 = 0. No floating-point experiment can reproduce this, because every machine number is rational: the tags must be chosen symbolically, as done above.
    • 

  • Thomae function. It is discontinuous at every rational but continuous at every irrational point; the set of discontinuities ℚ ∩ [0,1] has measure zero, so by Lebesgue's criterion it is Riemann-integrable, with integral 0. The numbers above show it: the lower sum is 0 and the upper sum decreases (slowly) towards 0; Riemann sums with rational tags depend on the arithmetic of N (N = 1009 prime gives about 2/N, N = 1000 gives a much larger value) but also go to 0. For Lebesgue, each set {f ≥ 1/k} is finite (≈ 3k²/π² points), so it has measure 0 and every simple-function approximation integrates to 0.
    • 

  • Efficiency. Riemann: N evaluations, O(1) memory, trivial to implement. Sampled Lebesgue: the same N evaluations plus binning and O(K) counters (our code also stores the values, O(N)); it adds nothing for deterministic 1-D integrals. Exact Lebesgue: O(K) work, but only when μ{f < t} is known in closed form or by root finding on monotone pieces, which is the real difficulty. The range-partition idea does pay off in other settings: in the theory (convergence theorems, measure-zero sets) and in Monte-Carlo estimation in high dimension, where measures of level sets are estimated by sampling.

Ex. 2 · Numerical computation of the normal CDF


Φ(x) = ∫−∞x φ(t)dt with φ(t) = e−t²/2/√(2π). Methods implemented: composite trapezoid and Simpson on Φ(x) = ½ ± ∫0|x|φ; the Maclaurin series of erf (alternating) and the series with positive terms ½ + φ(x)·(x + x³/3 + x⁵/(3·5) + …); a continued fraction for the tail Q(x) = φ(x)/(x + 1/(x + 2/(x + 3/(x + …)))); the Abramowitz–Stegun 7.1.26 erf approximation; and a double-precision rational approximation (Hart 1968, in West's 2005 form: two degree-6/7 polynomials for |x| < 7.07, a short continued fraction beyond). Reference values: computed with the arbitrary-precision library mpmath (40 digits) and cross-checked with the CDFLIB documentation (docs.rs/crate/cdflib), which lists Φ(1.96) = 0.9750021048517796, Φ(1) = 0.8413447460685429 and 1 − Φ(5) ≈ 2.866516·10−7, the same values.

Discussion (Ex. 2)




Why Φ has no elementary form (Liouville)


"Elementary" means built from rational functions, exp, log, algebraic functions (hence trigonometric ones) by arithmetic, composition and inversion. Liouville's theorem on integration in finite terms (1830s, in the form refined by Rosenlicht and Risch): if f and g are rational functions with g non-constant, ∫ f·egdx is elementary if and only if there is a rational function R with R′ + g′R = f, and then the integral equals R·eg. For φ we have g = −x²/2 and f = 1/√(2π) (a constant), so we would need R′ − xR = c with c ≠ 0. This is impossible: if R has a pole of order m ≥ 1 at some point, R′ has a pole of order m + 1 there while xR has order at most m, so nothing cancels the leading term; if R is a polynomial of degree d, xR has degree d + 1 while R′ has degree d − 1; and R = 0 gives 0 = c. Hence e−t²/2 has no elementary antiderivative, and neither has Φ. Note what this does not say: the definite integral over the whole line is perfectly computable, ∫−∞∞φ = 1 by the polar-coordinate trick, a tool outside the "find an antiderivative" world.


erf: exact representation, but not yet a number


The error function erf(z) = (2/√π)∫0ze−t²dt is the new special function created for exactly this antiderivative, and Φ(x) = ½[1 + erf(x/√2)] = ½·erfc(−x/√2) is then an exact analytical identity. But "exact" only means that the problem was renamed: erf(z) at a generic point is in general an irrational number that can be computed only by an algorithm: a power series, a continued fraction, numerical quadrature or a minimax rational approximation. That is what libraries do: they switch between several of these depending on the range of x (the same logic as our experiments).


What the experiments show


    

  • Quadrature is the most direct method but the least efficient: the trapezoid error is O(h²) (the end-point derivative φ′(x) ≠ 0 spoils superconvergence), Simpson O(h⁴), and each evaluation costs N exponentials. For a given accuracy, Simpson needs far fewer nodes (see the convergence plot, which plateaus near 10−16 because of round-off). In the far tail both lose all relative accuracy: Φ(−8) ≈ 6.2·10−16 is the difference ½ − ½, below the round-off of 0.5.
    • 

  • The Maclaurin series of erf is accurate to about 10−16 for small and moderate |x| (the table shows ~10−16 up to |x| = 3) and cheap to code, but its terms alternate and grow large before decaying when |x| is big: at x = 8 the error is already about 7·10−5. The series with all positive terms avoids that cancellation for x > 0, but for negative x it still computes 0.5 − (nearly 0.5), so relative accuracy in the left tail is lost.
    • 

  • The continued fraction is excellent in the tails (relative error ≈ 10−16 for |x| ≥ 3 with 60 terms) and useless near 0, where it converges slowly or not at all. Real libraries therefore combine a series or rational formula near the centre with a continued fraction or asymptotic expansion in the tails, and always compute the smaller tail directly, never as 1 − (nearly 1).
    • 

  • A&S 7.1.26 is a cheap handful of flops but only good to about 10−7 absolute; the rational (Hart/West) approximation reaches about 10−16 absolute error everywhere at a cost independent of x (two polynomials of degree 6–7 and one exp). Its relative error in the far tail is larger (5·10−11 at x = −5, 9·10−9 at x = −8 in our run) because the approximation targets absolute error; Cody's erfc algorithm in standard libraries targets relative error.
    • 

  • Efficiency ranking (see the timing table, which depends on your machine): rational and A&S need one exp and a few multiplications, the series need tens of terms, the continued fraction needs about 60 divisions, and quadrature needs N exponentials. So: use erfc/Φ from the standard library or a Cody-type rational approximation, not quadrature, which is useful for checking and for distributions that have no special-function form.
